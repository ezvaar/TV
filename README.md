# ezvaarTV

Free public live TV & radio player.

A lightweight, offline-capable HTML player with curated free-to-air and public streams from South Africa and around the world.

## Quick Start

1. Download [`ezvaarTV.html`](ezvaarTV.html)
2. Open it in any modern browser (Chrome, Edge, Firefox, Safari)
3. Click a channel and watch / listen

No install. No account. No app store.

## Features

- 235+ public channels (TV + Radio)
- Grouped by category (SABC, Freevision, News, Nature, Radio, etc.)
- Search
- Works on desktop and mobile
- Single HTML file — easy to host or keep offline
